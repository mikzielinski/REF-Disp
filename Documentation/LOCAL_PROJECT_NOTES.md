# Local Project Notes

## Scope

This file documents local implementation decisions and compatibility constraints for `REF-Disp`.

## Dispatcher Queue Item Compatibility

For this project/package set, `AddQueueItem` works with:

- `QueueType` (not `QueueName`)
- `FolderPath`
- `ItemInformation` as `Dictionary<String, InArgument>`

Do not use unsupported members from other activity variants (for example direct `SpecificContent`, `Deadline`, `PostponeFor`) unless package version explicitly supports them.

## InitAllSettings Rule

`Framework/InitAllSettings.xaml` is maintained without `InvokeCode` for the JSON bootstrap segment. Keep logic in declarative activities (`Assign`, `For Each`, etc.) for easier Studio compatibility.

## Runtime/Log Inputs

Main entry point supports:

- `in_OrchestratorQueueName`
- `in_OrchestratorQueueFolder`
- `in_EnvironmentType`

Runtime metadata fields include `RunId`, `RuntimeMode`, `AIEnabled`, `AIProvider`, queue metrics, and run duration.

## Local Generated Artifacts

The following folders are generated by Studio/runtime and are excluded via `.gitignore`:

- `.local`
- `.objects`
- `.project`
- `.settings`
- `.storage`
- `.tmh`

They may reappear after opening/running the project locally; this is expected.
